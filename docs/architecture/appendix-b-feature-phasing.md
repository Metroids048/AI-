# 附录 B：功能清单与阶段拆分

## P0：研究闭环最小可运行版

### 必须上线

- 假设录入
- 策略规则化
- 策略入库
- 历史回测
- 参数优化入口
- 样本外验证
- 模拟盘准入
- 执行日志
- 风险规则配置
- 每日复盘
- 失败原因沉淀

### 只定框架

- 宏观事件实时接入
- 新闻实时接入
- 社媒事件实时接入
- 外部研究源自动扫描
- 多市场统一扩展

### 不进入 P0

- 对外产品化包装
- 商业化能力
- 复杂多租户权限
- 全市场统一实盘执行

## P1：研究增强版

- `B/C/D/E` 数据源逐步启用
- Research / News / Twitter / Telegram Agent 在线化
- 管理后台分析能力增强
- 更多研究源接入

## P2：平台扩展版

- 多市场扩展增强
- 跨市场比较研究
- 更强知识检索与经验复用
- 更完整的运营与审计视图
