# 附录 B：功能清单与阶段拆分

命名说明：

- 本文的 `P0/P1/P2` 是实现 tranche 标签，不等同于仓库当前 `Phase 0/1/2` 状态。
- 截至设计收敛完成前，仓库整体仍处于 `Phase 0`（平台骨架 + 统一模型 + 设计冻结）。
- 第一条真实开发主线从本文 `P1` 开始，且首个里程碑止于“模拟盘准入就绪”，不含 live 实盘上线。

## P0：研究闭环最小可运行版

### 必须上线

- 假设录入
- 策略规则化
- 策略入库
- 历史回测
- 参数优化入口
- 样本外验证
- 模拟盘准入
- 执行日志
- 风险规则配置
- 每日复盘
- 失败原因沉淀

### 只定框架

- 宏观事件实时接入
- 新闻实时接入
- 社媒事件实时接入
- 外部研究源自动扫描
- 多市场统一扩展

### 不进入 P0

- 对外产品化包装
- 商业化能力
- 复杂多租户权限
- 全市场统一实盘执行

## P1：研究增强版

落地优先级（按顺序推进，前一项验收通过再进入下一项）：

1. **资金费率/基差套利策略优先落地**——现货多头 + 永续空头对冲（或反向）吃资金费，波动率无关、方向无关，作为系统的“底仓收益”策略。优先跑通它的原因：用一个确定性相对高的策略把 Validation Layer（回测→样本外→模拟盘）整条流水线先跑稳，而不是一上来就用方向性技术策略去检验流水线是否work。验收标准见 `validation-methodology.md`。
2. 技术策略框架化：缠论笔段/道氏趋势/MACD 等规则化为候选信号生成器，接入信号融合子模块（`SignalEnsemble`），并做相关性矩阵过滤
3. `B/C/D/E` 数据源逐步启用
4. Research / News / Twitter / Telegram Agent 在线化
5. 管理后台分析能力增强
6. 更多研究源接入

## P2：平台扩展版

- 多市场扩展增强
- 跨市场比较研究
- 更强知识检索与经验复用
- 更完整的运营与审计视图
