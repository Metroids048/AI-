# 附录 C：设计原则与非目标

## 设计原则

### 1. 研究闭环优先

任何模块价值，都要能映射回：

`假设 -> 规则化 -> 回测 -> 模拟盘 -> 实盘验证 -> 复盘 -> 迭代`

### 2. 策略资产化

策略必须沉淀为可版本化、可检索、可复盘的长期资产，而不是临时脚本。

### 3. 失败优先沉淀

失败案例、失效模式、风险触发和迭代记录，比单次成功更重要。

### 4. 风控高于收益

没有任何收益目标可以凌驾于 Validation 准入和 Risk Engine 约束之上。

### 5. AI 是研究员，不是交易员

AI 负责研究、整理、分析、编码、复盘和知识归档，不负责“拍脑袋决策”。

### 6. 分阶段启用，而非一次性终态

平台从总设计上支持长远终态，但实现按阶段推进，避免架构上过重、执行上过乱。

## 非目标

- 公众荐股平台
- 跟单产品
- 情绪预测工具
- P0 多租户 SaaS
- P0 商业化计费系统
- P0 全量实时接入五级数据源
- P0 全市场统一实盘执行网络
