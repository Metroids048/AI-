# pandas_ta_adapter.py 设计方案

## 目标
将 pandas-ta 库的 150+ 指标输出转换为项目标准的 TradeSignal 格式。

## 核心原则
1. **MIT许可证合规**：pandas-ta 是 MIT 许可，作为运行时依赖直接使用（pip安装，不复制代码）
2. **统一信号格式**：所有指标输出都转换为 TradeSignal(symbol, side, source, signal_time, reason, confidence)
3. **渐进式注册**：初期先注册 10 个常用指标，不一次性注册全部 150 个
4. **保留现有指标**：与现有 5 个手搓指标文件共存，不替换

## 初始注册的 10 个指标

根据方案要求，选择与现有 10 个手搓指标互补的指标：

### 趋势类（3个）
1. **SuperTrend** - 趋势跟踪指标，比 EMA 更灵敏
2. **Hull MA (HMA)** - 平滑移动平均，减少滞后
3. **ZLEMA (Zero Lag EMA)** - 零滞后EMA

### 动量类（3个）
4. **Stochastic RSI** - RSI的随机指标版本，更早发现超买超卖
5. **Squeeze Momentum** - TTM Squeeze，识别波动率突破
6. **CMO (Chande Momentum Oscillator)** - 相对动量

### 波动率类（2个）
7. **ATR Trailing Stop** - 基于ATR的动态止损位
8. **Keltner Channels** - 类似布林带但用ATR

### 量价类（2个）
9. **OBV (On Balance Volume)** - 累积量能
10. **MFI (Money Flow Index)** - 量价动量指标

## 信号转换逻辑

### SuperTrend 示例
```python
def _convert_supertrend(result, frame, symbol):
    """
    pandas_ta.supertrend() 返回三列：
    - SUPERT_{length}_{multiplier}: 趋势线值
    - SUPERTd_{length}_{multiplier}: 方向 (1=多头, -1=空头)
    - SUPERTl_{length}_{multiplier}: 长期趋势
    """
    direction_col = [c for c in result.columns if c.startswith('SUPERTd_')][0]
    latest_direction = result[direction_col].iloc[-1]
    previous_direction = result[direction_col].iloc[-2]
    
    # 方向切换时产生信号
    if previous_direction != latest_direction:
        if latest_direction == 1:
            return TradeSignal(
                symbol=symbol,
                side=TradeSide.LONG,
                source="technical_pandas_ta_supertrend",
                signal_time=_signal_time(frame),
                reason="supertrend_bullish_flip",
                confidence=0.7,  # 基准置信度
            )
        elif latest_direction == -1:
            return TradeSignal(
                symbol=symbol,
                side=TradeSide.SHORT,
                source="technical_pandas_ta_supertrend",
                signal_time=_signal_time(frame),
                reason="supertrend_bearish_flip",
                confidence=0.7,
            )
    return None
```

```python
PANDAS_TA_SIGNAL_REGISTRY = {
    "supertrend": {
        "compute": lambda frame: ta.supertrend(frame["high"], frame["low"], frame["close"]),

```

## 主入口函数

```python
def generate_pandas_ta_signal(
    *,
    name: str,
    symbol: str,
    frame: pd.DataFrame,
) -> TradeSignal | None:
    """
    Generate a TradeSignal from a pandas-ta indicator.
    
    Args:
        name: 指标名称，必须在 PANDAS_TA_SIGNAL_REGISTRY 中
        symbol: 交易对符号
        frame: OHLCV DataFrame
        
    Returns:
        TradeSignal or None if no signal
    """
    if name not in PANDAS_TA_SIGNAL_REGISTRY:
        raise ValueError(f"Unknown pandas-ta indicator: {name}")
    
    config = PANDAS_TA_SIGNAL_REGISTRY[name]
    
    # 检查最小周期
    if len(frame) < config["min_periods"]:
        return None
    
    # 计算指标
    result = config["compute"](frame)
    if result is None:
        return None
    
    # 转换为信号
    return config["convert"](result, frame, symbol)
```
