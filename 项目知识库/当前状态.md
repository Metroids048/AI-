## Recovery Contract

- Liveness recovery 只关闭新开仓，management / reconciliation / protection / reduce-only
  链继续运行；只有系统创建的 `LIVENESS_RECOVERY_HOLD:*` 可在健康 cycle 后自动解除。
- operator/manual pause 不会被自动解除；关键 task crash/stall 由进程级 worker supervisor 回收并重启。
- 恢复策略是 **5s / 15s bounded restart backoff**；第 3 次连续失败直接进入
  `AUTO_RECOVERY_EXHAUSTED`，不会等待一个未使用的 30s backoff。
