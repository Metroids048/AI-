# 风险控制与禁用清单

## 硬性规则

- 没有止损的单子拒绝执行。
- Validation 不通过不得进入 Paper。
- Paper 不稳定不得进入小资金 live。
- 禁止 Martingale。
- 禁止因主观感觉人工加仓。
- 禁止取消机器人止损。
- LLM 不可直接下单。
- LLM 超时或输出结构错误必须 fail closed。

## Binance Testnet / Paper 状态一致性

- 启用 Testnet mirror 后，必须 Binance 先成交，本地后记录。
- gateway 失败时本地不得 fill、open、close。
- gateway 失败要写入 Review failure 和 OrderExecution rejection。
- 本地 Paper 与 Testnet 状态不一致时，系统应进入只平仓或暂停新开仓模式。

## 仓位与杠杆

默认方向性策略：

- 单笔风险：1%。
- 最大杠杆：5x。
- 单策略/单 symbol 最大仓位：5%。
- 达到 trailing 阈值后止损只能收紧。

后续增强：

- 引入账户余额/仓位实时同步。
- 引入相关性与组合净敞口。
- 引入 OI、订单簿深度、成交量决定最大下单量。

## 数据质量

拒绝或暂停：

- K 线不新鲜。
- funding/OI 关键字段缺失。
- Binance REST/WS 长时间失败。
- 高影响新闻或宏观事件未处理。

## 策略质量

不得进入模拟盘：

- Sharpe <= 1.0。
- Profit Factor <= 1.3。
- Max Drawdown >= 25%。
- Expectancy <= 0。
- 样本外明显退化。
- 成本/滑点/资金费率后净收益为负。

## 人工经验的规则化要求

可以加入：

- 4h 看方向 + 15m 入场。
- 假突破/假跌破。
- MACD、RSI、ADX、EMA、VWAP、Bollinger 多指标确认。

需要先定义客观算法：

- 缠论一买、二买、三买、一卖、二卖、三卖。
- 笔、线段、中枢、背驰。
- 主观“盘感”“强弱”描述。

加入顺序：

1. 已有双通道质量基线。
2. 4h/15m + 假突破参数回测。
3. RSI/ADX/VWAP/OI/订单簿增强。
4. 缠论客观算法定义与离线标注。
5. 小资金 live 前的完整 Review 闭环。
