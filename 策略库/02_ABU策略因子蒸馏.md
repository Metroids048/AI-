# ABU 策略因子蒸馏

## 边界

- 来源：`https://github.com/bbfamily/abu`
- 许可：GPL-3.0
- 本项目策略：蒸馏研究-only，不复制运行时代码。

## 可蒸馏方向

### 1. 趋势跟踪

规则化候选：

- 高周期确认趋势：4h EMA 快慢线同向，Dow 高低点结构同向。
- 低周期找入场：15m 假跌破支撑后收回、VWAP reclaim、MACD histogram 同向。
- 风控：ATR 止损，达到 1.5R 后移动止损到入场价。

适合先实现：已基本进入 technical 通道。

### 2. 价格行为反转

规则化候选：

- 假突破：最新 K 线刺破前 N 根高点，但收盘回到区间内，上影线大于实体倍数。
- 假跌破：最新 K 线刺破前 N 根低点，但收盘回到区间内，下影线大于实体倍数。
- 只在高周期方向不冲突时启用，避免逆势接刀。

适合先实现：已加入 `price_action_false_breakout`，后续需要参数回测。

### 3. 市场报告与复盘模板

可吸收：

- 每日/每周行情结构复盘。
- 失败交易归因：趋势误判、震荡误判、消息面冲击、流动性不足、止损过紧。
- 将失败原因写入 `failure_reasons` 与 `iteration_history`。

适合阶段：Review Layer 强化。

### 4. 机器学习/因子研究流程

可吸收：

- 多因子候选 -> 指标计算 -> 样本外 -> 复盘淘汰。
- 不能让模型直接下单，只能输出可验证因子或 meta-label 结果。

适合阶段：P2，等基础回测和模拟盘统计稳定后再做。

## 不宜直接加入的内容

- 股票市场特有基本面字段。
- 无明确客观规则的主观形态判断。
- 依赖 ABU 运行时代码的策略类。
- 未通过成本、滑点、杠杆、极端行情压力测试的参数。
