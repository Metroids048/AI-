# 外部策略来源索引

## 已参考来源与可吸收内容

### Freqtrade

可吸收：

- 策略结构必须包含 OHLCV、指标、入场、出场、ROI/止损、定价、仓位调整。
- backtesting -> dry run -> live 的渐进流程。
- lookahead analysis / recursive analysis 思想，避免未来函数和指标不稳定。
- 指标只计算实际使用的列，避免低频自动循环的性能浪费。

平台映射：

- 对应 Strategy Layer 的策略契约字段。
- 对应 Validation Layer 的回测、样本外、偏差检查。
- 对应 Paper/Testnet 的 dry-run 纪律。

### Hummingbot

可吸收：

- 高频/做市/网格/套利类策略需要执行器、连接器、库存风险、挂单生命周期分离。
- 适合未来做 market making、grid、跨市场价差，但第一阶段只允许 Paper-only。
- 连接器思想可以映射到本项目 `ExchangeGateway`，但不直接引入外部运行时代码。

平台映射：

- Execution Layer：gateway、order lifecycle、reconciliation。
- Risk Layer：库存偏斜、单边暴露、撤单/挂单超时。

### QuantConnect Lean

可吸收：

- 事件驱动引擎、研究/回测/实盘边界、组合层和多资产扩展。
- 当前项目不引入 Lean runtime，只吸收架构与实验管理思想。

### vn.py

可吸收：

- Gateway / CTA strategy / Portfolio / Risk 的分层思想。
- 适合未来扩展 A股、期货、多账户，而不是当前 Binance-only 主链路。

### TradingAgents / TradingAgents-CN / Vibe-Trading / Qbot / daily_stock_analysis

可吸收：

- 多 Agent 分工：Research、News、Risk、Review、Strategy。
- 报告生成、知识沉淀、复盘和计划建议。

硬边界：

- Agent 不能直接下单。
- LLM 输出必须结构化校验。
- 所有建议必须转成 StrategyIdea/Draft 后走回测。

### ABU

当前许可边界：GitHub 仓库页面显示 GPL-3.0，因此只做蒸馏研究资产。

可吸收：

- 价格行为、趋势跟踪、市场报告、策略分类、研究流程。
- 只提炼客观规则，不复制代码。

## 需要继续补充的信息源

- Binance Academy：MACD、RSI、资金费率、合约风险、仓位与杠杆教育。
- OKX Learn / Bybit Learn：交易结构、假突破、合约风控、订单类型。
- 交易所官方 API 文档：Testnet/mainnet 差异、最小下单量、tick size、rate limit。
- 学术/实证来源：crypto trend following、funding arbitrage、volatility targeting、portfolio risk。

## 入库规则

- 任何外部来源先标注 license 和 license_policy。
- GPL/AGPL/LGPL 默认 `distilled_research_only`。
- unknown license 默认 `metadata_only`。
- 只有 MIT/Apache 等兼容来源，也仍先转为规则，不直接粘贴代码。
